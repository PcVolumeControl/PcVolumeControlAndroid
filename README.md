# PCVolumeControlAndroid
The Android component of the PcVolumeControl project

Download from:
https://play.google.com/store/apps/details?id=com.darkrockstudios.apps.pcvolumemixer

## Application icons
When the PC server supports icons (it lists `icons` in its `features`), each application shows its icon beside its name. Icons are cached on the phone, so they are only downloaded once. Older servers keep working as before, and their rows show a plain placeholder instead.
