# PCVolumeControlAndroid
The Android component of the PcVolumeControl project

Download from:
https://play.google.com/store/apps/details?id=com.darkrockstudios.apps.pcvolumemixer

## Application icons
When the PC server supports icons (it lists `icons` in its `features`), applications show their icon beside their name. Icons are cached on the phone, so they are usually downloaded only once. A plain placeholder takes the icon's place while an icon is loading or when none is available for an application. Servers without icon support still work; their rows show the placeholder.
